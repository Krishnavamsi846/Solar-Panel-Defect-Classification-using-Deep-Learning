# Solar Panel Condition Classifier

Academic Streamlit prototype for six-class visible-light RGB solar-panel condition classification.

## Model
Selected in the Kaggle research pipeline: **YOLOv8-Classification**

## Classes
- Bird-drop
- Clean
- Dusty
- Electrical-damage
- Physical-Damage
- Snow-Covered
